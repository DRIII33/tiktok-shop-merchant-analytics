# Looker Studio Dashboard Guide & Metric Documentation

## Dashboard Overview
The TikTok Shop Merchant Performance Dashboard provides real-time self-serve visibility into onboarding funnel performance, activation rates, 30-day GMV, and A/B experiment outcomes across regions and product categories.

## Core Metrics & Formulas
- Activation Rate (%): `(Total Activated Merchants / Total Fully Configured Merchants) * 100`
- 30-Day GMV: Cumulative gross merchandise volume achieved within 30 days of registration.
- Funnel Conversion Rate: Percentage of merchants advancing from registration to KYC, catalog upload, and first sale.

## User Navigation Instructions
- Filter Panel: Use top dropdowns to segment by Region, Category, or A/B Experiment Group.
- Funnel Chart: Click any funnel stage to drill down into category-specific drop-off rates.
- Diagnostic Table: Sort by `Support Tickets / Merchant` to identify operational friction points.
